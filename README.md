## About

I'm **Daisy**, a software developer from the UK building products, backend systems, infrastructure and performance sensitive software.

My current work spans SaaS platforms, distributed services, real time audio and broadcast systems, developer tooling, automation and JVM engineering.

I care about systems that are fast, observable, maintainable and reliable, from the interface people use to the infrastructure underneath it.
