I'm **Daisy**, a puppy girl and developer from the UK.

I started with Minecraft plugins and that's still where most of my projects live. These days I also spend a lot of time building **backend systems, infrastructure, tooling, and the occasional completely unnecessary rewrite**.

My main language is **Kotlin**, but I'm comfortable jumping between the JVM, TypeScript, and whatever else a project needs.

I care about **performance, clean architecture, reliability, and code that doesn't make future-me want to commit arson**.
